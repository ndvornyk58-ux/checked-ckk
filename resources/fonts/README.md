# Шрифты

**DejaVu Sans** (`DejaVuSans.ttf`, `DejaVuSans-Bold.ttf`) используется для экспорта в PDF,
чтобы корректно отображалась кириллица. Шрифт распространяется по свободной лицензии
(Bitstream Vera + public domain additions) и может включаться в сборку приложения.
Источник: https://dejavu-fonts.github.io/
