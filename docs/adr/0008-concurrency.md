# ADR-0008. Модель конкурентности фоновых задач

**Статус:** принято (PHASE 1), реализация — PHASE 2 (импорт) и PHASE 4 (Batch)

**Решение.** I/O — `QThreadPool` (через тонкий адаптер в GUI-слое), CPU — `ProcessPoolExecutor`.
Работа делится на чанки; между процессами передаются путь, смещение и параметры, результат —
компактные записи. Запись в БД — пакетами из одного места, чтобы не упираться в блокировки SQLite.

Pause/resume/cancel кооперативные: проверка флага на границе чанка; позиция сохраняется в
`job_tasks.checkpoint`, поэтому задача продолжается и после перезапуска приложения.
Retry — повтор только упавших задач с учётом `attempts`.

Число воркеров настраивается; по умолчанию `max(1, cpu_count - 1)`.
