# ADR-0005. Browser Integration без обхода защиты браузера

**Статус:** принято (PHASE 1), реализация — PHASE 4

**Решение.**
* Обнаружение браузеров и профилей — только для текущего пользователя ОС.
* **Firefox:** `cookies.sqlite` читается из копии файла (оригинал заблокирован работающим
  браузером), после диалога согласия для каждого профиля.
* **Chrome / Chromium / Edge:** значения зашифрованы ключами ОС (DPAPI и App-Bound
  Encryption на Windows, Keychain на macOS, libsecret на Linux). Приложение их **не
  расшифровывает**. Импортируются метаданные (имя, домен, путь, флаги, срок) —
  их достаточно для аудита безопасности; значения получают `value_state=browser_encrypted`.
* Если нужны значения — штатный экспорт пользователем (DevTools или расширение → JSON)
  и импорт через Import Center.

**Примечание.** Чтение баз cookies браузера может вызывать срабатывание антивируса/EDR.
Модуль явно сообщает пользователю, что и откуда читает, и ничего не делает в фоне.
