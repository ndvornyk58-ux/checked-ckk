# ADR-0006. Изоляция плагинов

**Статус:** принято (PHASE 1), реализация — PHASE 4

**Контекст.** Python-код, загруженный в процесс приложения, изолировать по-настоящему нельзя.

**Решение.** По умолчанию плагин выполняется в отдельном процессе-хосте; обмен — JSON-RPC
через stdin/stdout, с таймаутами и ограничением размера сообщений. `manifest.json`
(проверяется Pydantic-схемой) объявляет: id, версию, описание, `api_version` (semver,
проверка совместимости), точки расширения (`parser`, `validation_rule`, `security_rule`,
`exporter`) и запрашиваемые возможности. Возможность `cookie.values.read`
пользователь выдаёт явно; без неё плагин получает только метаданные.

Режим `trusted` (в процессе приложения) — только для парсеров, где важна скорость;
включается пользователем вручную и отмечается в интерфейсе.
