# ADR-0004. Границы Session Diagnostics

**Статус:** принято (PHASE 1), реализация — PHASE 4

**Контекст.** Инструмент, который берёт пачку cookies и проверяет их запросом к
произвольному сайту, функционально является «чекером» украденных сессий, независимо
от намерений автора. ТЗ прямо исключает такие сценарии.

**Решение.** Сетевая проверка возможна только для endpoint'а из allowlist проекта
со статусом:
* `local` — localhost, приватные диапазоны IP, зоны `.test`, `.local`, `.localhost`;
* `verified` — пользователь подтвердил контроль над доменом токеном в
  `/.well-known/cookie-inspector-verify.txt` или DNS TXT-записи.

Проверяется одна сессия за раз, помеченная в проекте как тестовая (`is_test_session`);
домен cookie должен соответствовать хосту endpoint'а. В Batch Processor сетевого шага нет.
Действует ограничение частоты запросов.

Результат описывает совпадение ответа с маркерами, которые задал пользователь
(код, заголовок, фрагмент тела), а не «валидность сессии» — правило 11 ТЗ.
