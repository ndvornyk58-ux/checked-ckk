# ADR-0007. Dataclass в горячем пути, Pydantic на границах

**Статус:** принято (PHASE 1)

**Решение.** `Cookie`, `Finding`, `SourceRef` — `@dataclass(frozen=True, slots=True)`:
сотни тысяч экземпляров при импорте, минимальные накладные расходы по памяти и времени.
Конструктор проверяет только внутреннюю согласованность (часовой пояс, `value_state`),
но не корректность по RFC — это задача движка правил с точными сообщениями.

Pydantic v2 — для данных, приходящих извне в свободной форме: настройки, манифесты
плагинов, пресеты, пользовательские правила валидации.
