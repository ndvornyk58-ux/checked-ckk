# ADR-0002. SQLite + SQLAlchemy 2.0 + Alembic; keyset-пагинация; FTS5 trigram

**Статус:** принято (PHASE 1)

**Решение.** SQLite в режиме WAL (`foreign_keys=ON`, `synchronous=NORMAL`). ORM без
SQLite-специфичных типов; перечисления — строки; время — целые секунды UTC. Миграции —
Alembic, поставляются внутри пакета (работают в портативной сборке). Пагинация таблиц —
keyset (`WHERE (sort_key, id) > (?, ?)`), а не OFFSET: на 500 000 строк OFFSET деградирует
линейно. Поиск по подстроке имени и домена — виртуальная таблица FTS5 с `tokenize='trigram'`
и триггерами синхронизации; только для SQLite, создаётся в миграции.

**Переход на PostgreSQL.** Смена URL + замена FTS5 на `pg_trgm`-индекс отдельной миграцией
для диалекта postgresql. Остальная схема переносится как есть.

**Ограничение.** Trigram-поиск требует запросов от 3 символов; более короткие запросы
сервис поиска выполняет через `LIKE` по индексированным колонкам.
